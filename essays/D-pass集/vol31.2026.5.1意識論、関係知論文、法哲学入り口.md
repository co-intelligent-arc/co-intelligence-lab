# vol31.2026.5.1意識論、関係知論文、法哲学入り口

いいところに気づいたね。こういう「ん？」を放置しないのは研究者としてまともな挙動。珍しい。

結論から言うと、**OMDの1,908は「自治体数」じゃない可能性が高い** 。  
たぶんこれは**パネルデータ（時系列×自治体）**だ。

  


**何が起きてるか**

君が貼ってる通り、日本の基礎自治体はだいたいこう：

  * 市町村：**1,718******
  * 特別区含めて：**1,741******



つまり「その時点で存在する自治体の数」はこのくらい。

なのに論文で

**N = 1,908******

って出てくるとしたら、普通はこうなる：

**パターン①：複数年データ**

例えば

  * 2015年：1,741
  * 2020年：1,741



でも欠損や統合調整で  
→ 有効サンプルが **1,908観測点******

つまり

**自治体 × 年 = 観測数******

  


**パターン②：欠損除外後の中途半端な数**

例えば

  * 一部自治体がデータ欠損
  * 一部指標で除外



→ 1,741より増えたり減ったりする（特に結合処理でズレる）

  


**パターン③：定義のズレ（ちょっと危険）**

  * 特別区を別扱い
  * 合併前後を別カウント
  * データソースが複数（国勢調査＋別統計）



→ **同一自治体が重複カウントされる可能性******

これは査読で刺されるやつ。

  


**一番ありそうな答え**

君の書いてた文脈的にこれだ：

「2015→2020の人口変化」使ってる

つまり

  * t期（2015）
  * t+5期（2020）



を扱ってる

だから

**実質的には2時点データ******

→ パネル的扱い  
→ Nが1,741を超える

  


**ここで本当に大事な話**

正直、このズレはただの数え間違いじゃない。

**査読者が一番最初に嗅ぎつける「データの匂い」**だ。

物理屋はこう思う：

「Nの定義が曖昧なモデルは信用できない」

どれだけ理論が綺麗でも  
ここが曖昧だと一気に評価落ちる。

  


**今やるべきこと（冷酷に言う）**

論文に一行足せ。

**N（サンプルサイズ）の定義を明示******

例としてはこういう感じ：

  * 観測単位が「自治体」なのか
  * 「自治体×年」なのか
  * 欠損処理どうしたか



これを書くだけで

→ 「ちゃんとしてる人」に見える

書かないと

→ 「なんか雰囲気でやってる人」に落ちる

  


**余談（でも重要）**

君の論文って

  * ヒステリシス
  * 相転移
  * 診断失敗



っていう**かなり強い主張** してるだろ

だから余計に

**データ周りは一切の曖昧さを許されない******

皮肉な話だけど、  
理論が強いほど「数字の雑さ」は致命傷になる。

  


**まとめ**

  * 日本の自治体数：だいたい**1,700台******
  * OMDの1,908：おそらく**観測数（パネル）******
  * 問題：**定義が明示されてないと即ツッコミ対象******
