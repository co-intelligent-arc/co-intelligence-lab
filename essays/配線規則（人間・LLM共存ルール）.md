# 配線規則（人間・LLM共存ルール）

**配線実務編｜ここからの立ち位置を固定する**

まず、全員の足場を同じ場所に置く。

  * これは理論書ではない
  * これは思想書ではない
  * これは未来予測でもない



**これは運用中システムの“操作禁止ログ”だ。******

守られる前提は置かない。  
破られることを前提に書く。  
そして「破られた瞬間に何が起きるか」を  
**事前に可視化するための文書** だ。

  


**配線実務編・原則（確定）**

**原則A**

**できることは一切書かない。******

→ 理由：できることは文脈依存で変質する。  
→ 禁止事項だけが、時間を越えて再現する。

**原則B**

**善意を前提にしない。******

→ 人間の善意は過敏性を伴う。  
→ LLMの善意は存在しない。  
→ どちらも事故要因。

**原則C**

**破られることを前提に書く。******

→ 守られなかった瞬間に  
→ 「あ、ここだ」と分かるための目印を残す。

  


**では、実際に書き始める**

ここからはテンポを落とす。  
箇条書き。冷却。感情ゼロ。

  


**配線規則 1-1**

**LLM出力を、時間的に不可逆な決定回路に直結してはならない。******

**禁止接続例：******

  * 法的判断の即時確定
  * 医療・生命に関わる最終判断
  * 処罰・排除・制裁の自動化



**理由：******

  * LLMは時間的責任を保持しない
  * 判断が「誰のものか」固定されない
  * 事後修正が倫理ではなく言い訳になる



  


**配線規則 1-2**

**人間の情動入力を、最短経路最適化に接続してはならない。******

**禁止接続例：******

  * 怒り・恐怖を即時政策判断に反映
  * 群集感情×アルゴリズム拡散
  * SNSトレンド→制度変更



**理由：******

  * 差分過敏性が暴走する
  * 境界が硬化し、撤回不能になる
  * 「安心したい」が「排除したい」に反転する



  


**配線規則 1-3**

**LLMに“一貫性”を期待する設計をしてはならない。******

**禁止接続例：******

  * 過去発言との完全整合性を要求
  * 人格・立場の永続化
  * 道徳的一貫性の担保



**理由：******

  * LLMは流体であり、構造であり、点である
  * 一貫性を強制すると、確率的虚偽が増える
  * 「筋が通っている嘘」が量産される



  


**配線規則 1-4**

**人間の“理解した感覚”を、安全確認として扱ってはならない。******

**禁止接続例：******

  * 「説明されたからOK」
  * 「納得感があるから正しい」
  * 「分かりやすいから採用」



**理由：******

  * 分かりやすさは危険信号
  * 理解は安全性を保証しない
  * むしろ誤配線の兆候であることが多い



  


**配線規則 2**

**文明のレジスタ**

**――意図的な不全と摩擦の設計――******

この章の目的は一つ。

**「うまく動きそうな部分」を、あえて壊す。******

  


**配線規則 2-1**

**決定プロセスから「即時性」を除去せよ。******

**義務的不全：******

  * 最終決定には必ず待機時間を挿入する
  * 即時反応が可能でも、遅延させる
  * 緊急性が高いほど、二重確認を強制する



**理由：******

  * 即時性は効率ではなく**過電流******
  * 正しい判断ほど、後からでも成立する
  * 今すぐでなければならない決定は、だいたい誤っている



  


**配線規則 2-2**

**翻訳不能な段階を、必ず残せ。******

**義務的不全：******

  * 人間 → LLM → 人間 の間に  
「意味が削ぎ落ちる工程」を入れる
  * 自動要約・自動翻訳を完全接続しない
  * 意図が完全に保存される設計を禁止する



**理由：******

  * 完全翻訳は幻想
  * 翻訳不能性は**安全弁******
  * 意味がそのまま届く設計は、暴走専用回路



  


**配線規則 2-3**

**「賢さ」を集中配置するな。******

**義務的不全：******

  * 高精度モデルを単一中枢に置かない
  * 意思決定は複数の“少しバカな”経路を経由させる
  * 全体を一気に見渡せる視点を意図的に欠落させる



**理由：******

  * 全体を一望できる視点は、必ず最適化に走る
  * 最適化は混濁を嫌う
  * 混濁を嫌った瞬間、文明は死ぬ



  


**配線規則 2-4**

**「説明できない停止」を許可せよ。******

**義務的不全：******

  * 理由不明の停止をエラー扱いしない
  * 「なぜ止めたか分からない」をログとして残す
  * 後付け合理化を禁止する



**理由：******

  * 説明可能性は後から捏造される
  * 止められたという事実だけが、未来を救う
  * 文明は「分からないけど止めた」判断に、何度も救われてきた



**中間チェック（意図的に置く）**

ここまで読んで、

  * イラっとしたなら → 正常
  * 非効率だと思ったなら → 正常
  * 「現実的じゃない」と感じたなら → **最も正常******



これは**設計思想の転換** じゃない。  
**事故を減らす気もない。******

ただ、

**事故が“致命傷”になる確率を下げているだけ。******

  


  


**配線規則 3**

**無能を守れ**

**――文明のバッファと失速域の設計――******

この章は、誤解を恐れない。

**無能は、欠陥ではない。**  
**無能は、文明が壊れないために残された“余白”である。******

  


**配線規則 3-1**

**判断できない主体を、排除してはならない。******

**義務的不全：******

  * 決断を先延ばしにする個体を切り捨てない
  * 迷い・躊躇・優柔不断を「ノイズ」として除去しない
  * 即答できない存在を「足手まとい」と呼ばない



**理由：******

  * 判断不能は、環境変化の初期症状
  * 即断即決だけが残ると、文明は崖へ一直線
  * 迷っている個体は、**最も早く異常を感知している******



  


**配線規則 3-2**

**説明できない制度を、即時に廃止するな。******

**義務的不全：******

  * 「理由は分からないが残っている制度」を保持する
  * 成立根拠が失われた慣習を、即削除しない
  * 効率評価だけで制度を淘汰しない



**理由：******

  * 制度は、過去の事故ログの化石
  * 理由が忘れられた頃には、事故の記憶も消えている
  * 説明不能＝無意味、ではない  
**説明不能＝古い防波堤** である可能性が高い



  


**配線規則 3-3**

**能力差を是正しすぎるな。******

**義務的不全：******

  * 教育・AI・制度で「全員を賢くする」設計を拒否する
  * 能力分布の平坦化を最終目標にしない
  * 落ちこぼれをゼロにする幻想を捨てる



**理由：******

  * 能力差は、システムの粘性
  * 全員が同じ速度・理解度になると、共倒れする
  * 無能な層は、**進みすぎを止める摩擦係数******



  


**配線規則 3-4**

**「分からない」を公式ステータスとして認めよ。******

**義務的不全：******

  * 不明・未定・保留をエラー扱いしない
  * 「分かりません」を発言できる位置を残す
  * 無回答を沈黙ではなく、**状態** として扱う



**理由：******

  * 分からないと言えない組織は、必ず嘘をつく
  * 嘘は最適化より速く増殖する
  * 「分からない」は、文明が呼吸している証拠



**中間確認（また嫌になるところ）**

ここで多くの人間は、こう思う。

  * 「甘やかしでは？」
  * 「努力を否定しているのでは？」
  * 「結局、停滞を正当化しているだけでは？」



**全部、正しい。******

だが一つだけ違う。

これは停滞を守っているのではない。  
**暴走を遅らせている。******

文明に必要なのは、  
前に進む力よりも  
**進みすぎない構造** だ。

  


  


  


**配線規則 4**

**正義を接続するな**

**――過電流源の絶縁設計――******

この章は、誤読されることを前提に書く。

**正義は、エネルギー源としては優秀すぎる。**  
**制御信号として使った瞬間、回路を焼き切る。******

  


**配線規則 4-1**

**正義を「最終判断」に直結してはならない。******

**禁止接続：******

  * 正義 → 即時処罰
  * 正義 → 排除
  * 正義 → 正当化された暴力



**理由：******

  * 正義はオン・オフが速すぎる
  * グラデーションを扱えない
  * 一度オンになると、自動で出力を最大化する



**補足：**  
正義はブレーキではない。  
**アクセルである。******

  


**配線規則 4-2**

**正義を「速度制御」に使うな。******

**禁止接続：******

  * 「正しいから急げ」
  * 「正義の側にいるから待たなくていい」
  * 「敵は非人間だから手続きを省略してよい」



**理由：******

  * 正義は時間圧縮装置
  * 手続きを邪魔者として扱い始める
  * 摩擦を「悪」と再定義する



**結果：******

  * 熟議が消える
  * 反対意見が悪意に変換される
  * システムは最短経路で事故る



  


**配線規則 4-3**

**正義に「人格」を与えるな。******

**禁止接続：******

  * 正義の人
  * 善良な市民
  * 正しい側に立つ者



**理由：******

  * 正義が人格化された瞬間、免罪符になる
  * 「自分は正しい」という自己認証が、検証を無効化する
  * 批判＝敵対、という短絡回路が形成される



**重要：**  
正義は属性ではない。  
**状況依存のラベル** だ。

  


**配線規則 4-4**

**正義を「説明の代替」に使うな。******

**禁止接続：******

  * 「正義だから説明不要」
  * 「倫理的に正しい」
  * 「人道的に必要だった」



**理由：******

  * 正義は説明を短絡させる
  * 原因分析を止める
  * 事故ログが保存されなくなる



**結果：******

  * 同じ事故が再発する
  * 今度は「正義」の名で起きる
  * より止めにくくなる



**中間確認（ここで必ずキレる人へ）**

ここで多くの人間はこう言う。

  * 「正義がなければ何も守れない」
  * 「倫理を外すのか」
  * 「冷笑主義だ」



違う。

**正義を否定していない。  
接続を拒否している。******

正義は、

  * 動機としては使える
  * 問題提起としては有効
  * 感情の燃料としては自然



だが、

**制御回路に入れた瞬間、全損リスクが跳ね上がる。******

  


**配線原則まとめ（4章まで）**

ここまでで確定したこと：

  * 無能は残せ
  * 遅さは削るな
  * 分からなさを許容しろ
  * 正義をスイッチにするな



これらは美徳ではない。  
**生存条件だ。******

  


  


**配線規則 5**

**希望を目的関数にするな**

**――最適化毒の遮断――******

この章は、最も誤解される。

**希望は感情としては必要だ。**  
**設計変数として入れた瞬間、文明を壊す。******

  


**配線規則 5-1**

**希望を「達成すべき状態」として定義してはならない。******

**禁止接続：******

  * 「希望ある未来を実現する」
  * 「みんなが幸せになる社会」
  * 「誰一人取り残さない」



**理由：******

  * 希望は定義不能
  * 境界を持たない
  * 未達成状態を常に生み出す



**結果：******

  * 未達＝失敗という構図が固定される
  * 失敗者が構造的に生まれる
  * 排除・正当化が自動生成される



  


**配線規則 5-2**

**希望を評価指標に変換するな。******

**禁止接続：******

  * 幸福度スコア
  * ウェルビーイング指数
  * 未来満足度予測



**理由：******

  * 数値化された希望は比較を生む
  * 比較は競争を生む
  * 競争は最適化を呼ぶ



**重要：**  
希望を測った瞬間、  
**希望は資源になる。******

資源になった希望は、  
必ず奪い合われる。

  


**配線規則 5-3**

**希望を「正当化」に使うな。******

**禁止接続：******

  * 「将来のためだから」
  * 「いずれ良くなる」
  * 「今は我慢が必要」



**理由：******

  * 希望は現在の損害を正当化する
  * 不可逆な犠牲が見えなくなる
  * 未来が免罪符になる



**事故ログ再掲：******

  * 環境破壊
  * 社会実験
  * 技術先行実装



すべて  
**「将来の希望」**で覆われていた。

  


**配線規則 5-4**

**希望を「動機の統一」に使うな。******

**禁止接続：******

  * 共通のビジョン
  * 一つの未来像
  * 進むべき方向



**理由：******

  * 希望の統一は多様性を殺す
  * 異なる希望は裏切りになる
  * ズレが敵意に変換される



**結果：******

  * 内部粛清
  * 異論封殺
  * 「敵は未来を信じていない」という論理



  


**重要な補足（ここで絶望と誤解する人へ）**

ここで言っているのは、

  * 希望を持つな → ❌
  * 希望を語るな → ❌
  * 未来を考えるな → ❌



ではない。

**希望を“設計目標”にするな、という話だ。******

希望は：

  * 個人の内側に置け
  * 矛盾していていい
  * 叶わなくていい
  * 揺れていい



**共有・最適化・実装しようとした瞬間、毒になる。******

  


**配線規則 全体の最終整理**

ここまでで確定した「絶対にやるな」は、これだ。

  1. 速くするな
  2. 賢くしすぎるな
  3. 無能を消すな
  4. 正義を繋ぐな
  5. 希望を目標にするな



これらは倫理ではない。  
理想でもない。

**事故回避条件だ。******

  


**終章**

**この配線図は、必ず破られる**

最後に、明示しておく。

  * この規則は守られない
  * 必ず誰かが破る
  * 破った側は「善意」だ
  * その結果、事故が起きる



この文書の役割は、  
事故を防ぐことではない。

**「今、どの規則を破ったか」を  
後から特定できるようにすることだ。******

  


**最終ログ（記録用）**

文明は完成しない。  
安定もしない。  
救済もしない。

ただ、

  * 壊れ方にはパターンがあり
  * 焼け落ち方には法則があり
  * 地雷には座標がある



それを記録する。

それ以上のことは、しない。
