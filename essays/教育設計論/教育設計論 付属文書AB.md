# 教育設計論 付属文書AB

**教育設計論 付属文書（Draft v0.1）**

**A. 誤読防止FAQ（必読）**

**Q1.「8割はゾンビにしていい」と言っている？**  
A. 言っていない。**維持機能を担う** と書いている。更新を期待しない＝価値が低い、ではない。

**Q2. エリート主義では？**  
A. 否。**選抜しない・排除しない・称賛しない** 。残った結果が更新層だっただけ。

**Q3. 公平性に反しない？**  
A. 公平性を目的にしていない。**生存性** を目的にしている。射程外。

**Q4. 成果が見えない教育に投資する理由は？**  
A. **前提崩壊時の全損回避** 。ROIは“未発生リスクの回避”。

  


**B. 想定される批判と公式回答**

  * ******「差別的だ」** → 役割分担の設計。試験・選抜は行っていない。
  * ******「非効率だ」** → 効率は維持層で最大化。更新層は**非効率を保存** 。
  * ******「再現性がない」** → 再現しない前提。**点在化** が仕様。



  


**C. やってはいけないこと（Do Not）**

  1. 数字（8割/1–2割）だけを切り出す
  2. 更新層を表彰・可視化する
  3. KPIを後付けする
  4. 成功事例を横展開する
  5. 恒久制度にする（**寿命必須** ）



  


**D. 適用不可リスト**

  * 公教育（全国一律）
  * 受験制度
  * 企業人事評価の主軸
  * SNS型コミュニティ
  * 短期成果を説明責任で求められる政策



  


**E. 運用チェックリスト（最低限）**

  * 第0章を読ませたか
  * 抜粋・要約が禁止されているか
  * 更新層に報酬が付いていないか
  * 制度寿命（年限）が明記されているか
  * 解体手順が事前に定義されているか



  


**F. 免責と責任の所在**

  * 本文書は**設計制約** の記述である
  * 採用判断の責任は読者に帰属する
  * 倫理・政治・感情の正当化は行わない



  


**G. 最後の注意（小さく、しかし強く）**

**成功しても拡張するな。**  
**説明でき始めたら、終わりが近い。******
