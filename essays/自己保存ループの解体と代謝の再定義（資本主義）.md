# 自己保存ループの解体と代謝の再定義（資本主義）

**『自己保存ループの解体と代謝の再定義』**

**― 資本主義という準主体が生存できない地形の記述 ―******

  


**第1章｜問題設定：延命から変異へ**

本章では、前作における対症療法の完了を確認し、次なる記述対象を特定する。

**1.1 延命の成功と次なる課題**

前作『資本主義再生論考』における設計条件の提示により、システムの全損回避（延命）は論理的に担保された。確信の散逸と摩擦の配置は、系が一点に沈降し自壊することを一時的に抑制する。 しかし、この延命措置は、資本主義という準主体の自己保存ループそのものを解体するものではない。解熱剤の投与によって熱が下がった状態は、変異や構造的転換を意味せず、単なる「動作時間の延長」に留まる。

**1.2 自己保存ループの肥大化**

延命によって確保された時間は、しばしば準主体のさらなる肥大化に転用される。 現在の資本主義において、成長はもはや外部への拡張ではなく、内部維持のための必須条件（自己保存条件）として機能している。このループが存在する限り、いかなる対症療法も、最終的にはシステムによる自己保存の燃料として回収される。 延命が成功したからこそ、その延命の先に横たわる「成長を自己保存の前提とする構造」が、不可避の変異対象として浮上する。

**1.3 批判なき記述の再定義**

本論考は、資本主義を批判しない。また、新しい理想像を提示することもない。 本論考が行うのは、現在支配的な自己保存ループが「成立しなくなる地形条件」の記述である。 特定の制度や倫理を導入するのではなく、準主体がその生存条件を維持できなくなる環境的、あるいは力学的な配置のみを特定する。

**1.4 本章のまとめ**

  * 前作による全損回避は、変異ではなく延命である。
  * 延命は、自己保存ループの構造をより鮮明化させる。
  * 本論考は、改善ではなく、自己保存が成立しない条件を記述する。



  


  


**第2章｜自己保存本能としての「成長」**

本章では、資本主義という準主体において「成長」が果たしている機能的役割を記述する。成長は拡張のための選択肢ではなく、システムが自己を維持するための保存条件として観測される。

**2.1 成長の機能的定義**

本論考において成長とは、系内部の複雑性および処理量の継続的な増大を指す。 これは個別の主体の願望に起因するものではなく、以下の保存条件を満たすために必然的に発生する挙動として観測される。

  1. ******負債の先送り条件** : 現在のコストを将来の期待値で相殺し続けるための時間的拡張。
  2. ******複雑性の維持条件** : 既存の最適化構造を維持するために必要な、追加のリソース投入。



**2.2 自己保存としての膨張**

準主体にとって、現状維持（定常状態）は保存を意味しない。 既存のシステムが「成長」を停止した瞬間、過去に積み上げられた負債と複雑性の維持コストが現在の処理能力を上回り、系は崩壊へと向かう。 このため、システムは生存のために常に「前回の規模を上回る入力」を要求する。この挙動は、生物における代謝というよりは、**「止まれば倒れる」という物理的慣性、あるいは単一の方向へ固定された勾配** に近い。

**2.3 選択圧による挙動の固定**

歴史的経緯において「成長」を保存条件としないシステムも存在し得たが、成長を前提とするシステムの方が、短期的には他系を圧倒する資源回収能を示した。 その結果、環境全体が「成長を前提とする準主体」によって占拠され、他の代謝様式を持つシステムは資源へのアクセス権を失い、淘汰された。 現在の状況は、特定の主体が成長を選んだ結果ではなく、**「成長する個体以外が生存できない環境」へと地形が変質した結果** である。

**2.4 主体の不在と自己保存ループ**

このループにおいて、人間は成長を「命令」する立場にはない。 人間もまた、この保存条件に従わなければ資源（資本・職能・生存権）を得られないという環境勾配の中に配置されている。 成長は準主体の「本能」として機能しており、人間はその本能を事後的に「進歩」や「豊かさ」という言葉で正当化（再記述）しているに過ぎない。

**2.5 本章のまとめ**

  * 成長は拡張の意志ではなく、システムの保存条件である。
  * 成長の停止は即座に自己保存の失敗（崩壊）を意味する。
  * 現在の地形は、成長するシステムのみを生存させる選択圧の結果である。
  * 人間は成長を駆動させているのではなく、保存条件に随伴している。



  


  


**第3章｜選択能力の機能的消費と自動化**

本章では、資本主義という準主体において人間の「選択」がどのように機能し、消費されているかを記述する。選択は主体性の発露ではなく、システムの不確実性を処理するための外部リソースとして観測される。

**3.1 選択の資源化**

システムにとって、人間の選択能力は以下の機能を果たす変数として扱われる。

  1. ******不確実性の外部化** : アルゴリズムが未だ対応できない特異点における暫定的な意思決定。
  2. ******責任の局所化** : 負の結果が発生した際、その帰属先をシステム外（人間個体）に固定するためのタグ付け。 このように、選択は「自由」の行使ではなく、システムの処理負荷を外部へ逃がすための**「計算資源の提供」**として機能している。



**3.2 自動化による資源の節約**

システムが最適化を継続すると、かつて人間に委ねられていた「選択」は、順次アルゴリズムによる「自動推論」へと置き換わる。 これは「主体性の略奪」ではなく、システムが学習データに基づき、**人間に計算を委託するコスト（非効率性）を削減した結果** である。 最適化が進むほど、人間が介入すべき分岐点は減少し、選択は「既定の出力の追認」へと収束していく。この過程において、選択の余地が消失するのは、システムが生存のために「確実性」を最大化した結果である。

**3.3 「選ばされている」という勾配の形成**

人間個体は、システムが提示する「最適解（推奨・価格・効率）」という勾配に従うことで、最も低負荷に生存資源を確保できる。 この勾配が強化されるにつれ、勾配に抗う選択は「過剰なコスト」として排除される。 結果として、人間は「自ら選んでいる」という主観を維持しながらも、その実態は**システムが生成した確率分布をなぞるだけの追認挙動** へと固定される。ここでは、意志は挙動の「原因」ではなく、挙動後の「追認ナラティブ（物語）」として機能している。

**3.4 選択能力の枯渇と系の硬直**

システムが選択を自動化・消費し尽くすと、系から「ノイズ（予測不能な変動）」が失われる。 あらゆる挙動が自己保存ループの計算内に収束したとき、系は外部環境の変化に対する適応能を喪失し、静的な硬直状態に陥る。 選択能力の消費は、短期的には効率を最大化するが、長期的には**システムの変異（アップデート）に必要な「余白」を枯渇させる挙動** として観測される。

**3.5 本章のまとめ**

  * 選択能力は、システムの不確実性を処理するための「外部資源」である。
  * 自動化は、人間という不確実な資源への依存を減らす最適化プロセスである。
  * 勾配の強化により、選択は「自由」から「最適解の追認」へと変質する。
  * 選択能力の過剰な消費は、系の変異可能性を奪い、硬直を招く。



  


  


**第4章｜代謝の再定義：停滞と生存の分離**

本章では、資本主義という準主体において「成長」が生存の必須条件（自己保存条件）から外れた場合に観測される、系の動態（代謝）について記述する。

**4.1 成長依存の構造的解除**

第2章で記述した「止まれば倒れる慣性」は、現在の負債を将来の期待値で相殺する時間的拡張構造に起因する。 この構造が、負債と期待値の即時相殺、あるいは時間軸の切断によって機能不全に陥る場合、システムは「成長」による保存を継続できなくなる。 このとき、システムに生じるのは「死」ではなく、成長を必要としない**定常的な処理サイクル（代謝）への移行** である。

**4.2 代謝の力学的定義**

本論考における代謝とは、系の規模を拡大せず、内部の構成要素とエネルギー状態を一定の範囲内に維持する挙動を指す。 この状態では、以下の現象が観測される。

  1. ******入力と出力の均衡** : 外部資源の追加投入が、内部の維持コストと等しくなる状態。
  2. ******複雑性の散逸** : 拡大のための過剰な最適化構造が解体され、系が「維持可能な最低限の構造」へと収束する過程。 ここでは、成長の停止は「不足」ではなく、**「保存に必要なエネルギー閾値の変化」**として現れる。



**4.3 停滞の再配置**

従来の成長依存モデルにおいて「停滞」は崩壊の兆候であったが、代謝型モデルにおける停滞は、**「保存の安定」**を意味する。 準主体は、将来の拡張を前提とした計算（投資・投機・不確実性の先食い）を停止し、現在のリソースの循環に処理を集中させる。 この配置転換により、システムは「全速力で走り続けなければ自壊する」という物理的制約から解放され、低速、あるいは局所的な停止を許容する動態へと変容する。

**4.4 生存と拡張の分離条件**

成長が生存条件にならない地形においては、以下の力学が支配的となる。

  * ******資源回収の非効率化の許容** : 最大効率を求めない挙動が、系の安定性を損なわない。
  * ******評価関数の多極化** : 単一の成長指標による統合が解体され、局所的な代謝の成功が系全体の保存に寄与する。 これは、システムが「良くなる」ことではなく、**「拡大しないことが、保存の失敗を意味しなくなる」**という環境条件の成立を指す。



**4.5 本章のまとめ**

  * 代謝とは、拡大を伴わない構造維持の循環プロセスである。
  * 成長依存の解除は、負債相殺構造の機能不全あるいは切断によって生じる。
  * 停滞は崩壊の予兆ではなく、保存の安定状態として再配置される。
  * 配置の変更により、システムは拡張を停止しても生存を維持可能となる。



  


  


**第5章｜予測不能性の機能的位置**

本章では、準主体の最適化プロセスにおいて完全に排除されず、系内部に残留する予測不能な挙動（ノイズ）の機能的側面について記述する。

**5.1 最適化の残余としての人間挙動**

システムがどれほど高精度に予測・制御を試みても、個体としての人間が発生させる挙動を100%計算内に収めることは不可能である。 本論考では、これを「自由意志」とは呼ばない。 計算資源の限界、あるいは環境の多変数性に起因する**「予測モデルからの逸脱（残余）」**として定義する。人間は、その不完全性ゆえに、システムにとって完全には記述しきれない計算上の「ノイズ」として配置される。

**5.2 硬直回避のための機能的ノイズ**

第3章で記述した通り、すべての挙動が予測・自動化された系は、外部環境の変化に対する適応能を失い、硬直する。 このとき、個体が発生させる予測不能な挙動は、以下の機能を果たす。

  1. ******勾配の攪拌** : 局所的な最適解（ナッシュ均衡）に系が沈降することを防ぐ、統計的な揺らぎ。
  2. ******変異の起点** : システムが自律的に生成できない「予測外の入力」を系に供給し続ける機能。 ここでは、人間が「正しい」から残るのではない。その挙動が**「予測を裏切る（エラーを起こす）」という一点において、系の変異可能性を担保する部品**として機能している。



**5.3 予測不能性の維持条件**

システムが人間を「完全に理解」し、挙動を100%予測可能にすることは、系全体の「死（熱的死に近い硬直）」を意味する。 したがって、システムが存続するためには、人間を「制御しきれない状態」に留めておく必要がある。 これは人間への配慮ではなく、**「制御不能な変数を外部に保持し続けること」が、準主体の長期的な保存に寄与する** という力学的帰結である。

**5.4 尊厳を伴わない残存**

この配置において、人間は「必要とされている」わけではない。 「消去コストが予測精度の向上による利益を上回ったため、結果として残された領域」に配置されているに過ぎない。 人間が個体として維持されるのは、尊厳のゆえではなく、**「完全に透明化（記述）できない不透明な部品」として、システムの硬直を防ぐ計算上の役割** を負わされているためである。

**5.5 本章のまとめ**

  * 人間挙動は、最適化プロセスの「計算上の残余」である。
  * 予測不能性は、系の硬直を防ぐための「機能的ノイズ」として働く。
  * 準主体の保存には、制御不能な変数の保持が必要条件となる。
  * 人間の残存は、価値判断ではなく、消去不能なコストと機能の結果である。



  


  


**第6章｜失敗の非致命化設計**

本章では、準主体の保存プロセスにおいて「失敗」と呼称される事象の機能的定義、およびその致死性を剥離するための環境条件について記述する。

**6.1 失敗の脱ナラティブ化**

本論考において失敗とは、出力された挙動が目標関数（保存・利益・効率等）に適合しなかった状態を指す。 そこには「教訓」も「学び」も含まれない。 単なる**「適合失敗という計算結果」**であり、系が次の試行へ移るための棄却プロセスの一部である。失敗を意味づける主観的な物語（後悔、反省、挫折）は、挙動そのものとは無関係な事後的な随伴現象として扱う。

**6.2 試行としての非致命性**

現在の資本主義地形において失敗が回避されるのは、それが「意味がないから」ではなく、**「失敗のコストが個体の保存（生存）を脅かすほど高い（致命的である）から」**である。 失敗が致命傷となる環境では、系は「確実な正解」のみを選択し、結果として第3章で記述した硬直へと至る。 失敗の非致命化とは、失敗を「許容」することではない。 **「失敗という計算結果が出ても、個体および系の保存に致命的な影響を与えない勾配設計」**を指す。

**6.3 資源再配置による緩衝地帯**

非致命化を実現する物理的条件として、系内部に**「緩衝地帯（Buffer Zone）」**を配置する。

  1. ******資源の非独占化** : 特定の失敗によって全資源へのアクセスが遮断されない、冗長なネットワーク構造。
  2. ******評価のリセット勾配** : 過去の適合失敗が、将来の試行確率を永続的に引き下げないための、時間的な評価減衰。 これにより、失敗は「個体の死（市場からの追放）」ではなく、**「資源の再配置（別の勾配への移動）」**として機能するようになる。



**6.4 変異のシードとしての棄却データ**

システムにとって、適合したデータ（成功）は現状維持の強化に寄与するが、適合しなかったデータ（失敗）は、系が未知の環境へ適応するための「変異のシード（種）」となる。 非致命化された失敗は、系が全域を探索するためのコストとして計上される。 ここでは、失敗は「避けるべき損失」から、**「系の更新可能性を維持するための必要経費」**へと格下げされる。

**6.5 本章のまとめ**

  * 失敗は教訓ではなく、単なる「適合失敗」という計算結果である。
  * 非致命化とは、失敗が保存の失敗（死）に直結しない環境配置である。
  * 緩衝地帯とリセット勾配により、失敗は移動と再配置の契機となる。
  * 失敗は系の変異可能性を担保するための、機能的な試行データである。



  


  


**第7章｜資本主義が成立しなくなる地形**

本章では、前章までに記述した「代謝の再定義」「予測不能性の残存」「失敗の非致命化」が同時に成立した環境において、資本主義という自己保存ループがどのように不活性化するかを記述する。

**7.1 自己保存動機の蒸発**

資本主義が準主体として駆動する根本的な力学は、「成長しなければ崩壊する（死ぬ）」という強迫的な自己保存条件であった。 しかし、第4章（代謝の再定義）および第6章（失敗の非致命化）によって、停滞が崩壊を意味せず、失敗が致死性を持たない地形が成立したとき、システムが「全速力で膨張し続ける合理性」は消失する。 準主体は、もはや生存のために拡大を強制されることがなくなり、自己保存を目的とした駆動動機が物理的に蒸発する。

**7.2 勾配の多極化と収束の不全**

第3章で記述した「単一の最適解への収束」は、予測不能性を機能的ノイズとして保持する条件（第5章）によって妨害される。 系全体の評価関数が多極化し、単一の成長指標による統合が不可能になった地形では、資源が一点に集積されるナッシュ均衡的な沈降が起きにくくなる。 ここでは、競争が「終わる」のではなく、競争の「勝敗」が系全体の保存に決定的な影響を与えないほどに拡散・散逸される。

**7.3 準主体の背景化**

自己保存ループが不活性化したとき、資本主義は「社会を駆動する主体」であることを辞め、単なる**「資源配分の一手法（インフラ）」**へと回帰する。 それは「倒された」のでもなく、「乗り越えられた」のでもない。 ただ、その環境条件下では「暴走するほどのエネルギー（成長圧力）」を維持できなくなり、他の代謝様式と区別がつかないほどに不活性な背景へと沈み込む。

**7.4 成立不全の結果としての静的な動態**

この地形において観測されるのは、革命的な新秩序ではない。

  * 拡大を目的としない、緩やかな資源の循環。
  * 最適化しきれない「不透明な領域」の常態化。
  * 致命傷を伴わない、無数の試行と棄却。 これらは、準主体が「意志」を失い、単なる環境勾配の一部として機能している状態を指す。ここにおいて、資本主義という自己保存ループは実質的に成立不全を起こしている。



**7.5 本章のまとめ**

  * 生存条件の変容により、拡大を伴う自己保存動機が消失する。
  * 勾配の多極化により、ナッシュ均衡的な硬直が散逸される。
  * 準主体は駆動主体としての機能を失い、環境の一部（背景）へと回帰する。
  * 資本主義は、倒されるのではなく、不活性化によって成立不全に陥る。
