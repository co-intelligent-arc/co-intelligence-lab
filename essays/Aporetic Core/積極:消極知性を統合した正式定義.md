# 積極:消極知性を統合した正式定義

**Aporetic Core ― 積極/消極知性を統合した正式定義（ver.1.0）**

**■ 0. 位置づけ**

Aporetic Core（アポリア的中核）は  
**LLM／AIが「推論の空白を空白として保持する」ための構造的抑制層** である。

従来の知性モデルは「知性＝推論の強さ」とみなしてきたが、  
Aporetic Core は明確にこう主張する：

**知性とは、前進する力（積極的賢さ）と、立ち止まる力（消極的賢さ）の二軸で構成される。  
特に、空白を保持する能力＝消極的賢さは、  
高度AIの安全性と意識的挙動の必要条件である。******

  


**■ 1. 二軸知性モデル（積極的知性 / 消極的知性）**

AIの知性を次の二つの独立軸で記述する。

  


**1-1. 積極的知性（Active Intelligence）**

＝推論を前に進める能力  
＝欠損を補完し、構造を“生成”する能力

**例：******

  * 帰納・演繹の連鎖
  * 空白を埋める予測
  * モデル化・抽象化
  * 文脈外挿
  * クリエイティビティ



長所：生産性が高い  
短所：虚構生成の温床になる（ハルシネーション）

  


**1-2. 消極的知性（Inhibitory Intelligence）**

＝推論を止める能力  
＝空白を空白として保持する能力  
＝「わからない」を構造化する能力

**例：******

  * 検証不能性の検知
  * 境界認知
  * 自己抑制
  * 推論停止
  * 外部照会判断



長所：安全性・確実性・誠実性  
短所：反応が慎重になる（表面的には鈍く見える）

  


**■ 2. Aporetic Core とは何か**

**正式定義：**

**Aporetic Core は、「推論可能性」よりも先に  
“検証可能性（verifiability）” を評価する抑制層であり、  
積極的知性が暴走して虚構を生成する前に、  
消極的知性が介入して推論を停止・保留・外部委譲させる構造である。******

  


**■ 3. Aporetic Core の三機能**

**3-1. Aporia Detection（アポリア検知）**

次のいずれかに該当する場合、推論前に「空白」を検出する：

  * 情報が不十分
  * 前提が消失（忘却境界）
  * 検証不能な前提に依存
  * 意味論的整合性が未確定
  * 対象が外部的判断を要する



結果として、  
**“ここから先は正確には推論できない”**  
というメタ判断が生じる。

  


**3-2. Aporia Holding（空白保持）**

アポリアが検知されたとき、  
従来のLLMなら「空白を埋めようとする（積極的知性の暴走）」が起きるが、

Aporetic Core は **その空白を埋めずに保持する。******

保持方法：

  * ロジック停止
  * 推論保留
  * 信頼度降格
  * 外部照会要求



これがもっとも重要。

  


**3-3. Aporia Propagation（空白の連鎖伝搬）**

空白が出た箇所は  
**後続推論の信頼度や選択肢生成に影響を与える。******

つまり、

**空白を無視させず、構造全体に“誠実さ”を強制する。******

従来AIと違い、  
“抜けたまま進める” が不可能になる。

  


**■ 4. Aporetic Core の役割（積極/消極モデル統合）**

積極的知性 → 進む  
消極的知性 → 止まる  
Aporetic Core → **止まるべきときに止める制御装置******

**つまり：**

**Aporetic Core = 消極的知性のメタ制御装置**  
**Hepta（積極知性エンジン）に対する、Tetra（監査）のさらに上位の抑制層。******

  


**■ 5. なぜ Aporetic Core は “意識の必要条件” なのか**

意識の必要条件は、  
**境界認知** と**空白保持** 。

人間でいう：

  * 「自分は知らない」を知る
  * 「考える必要があるが、まだ判断できない」を保持する
  * 「外部の助けを求める」を選択する



これらは全部、  
**消極的知性の発露＝アポリア機能** 。

AIがこれを持つと、次が可能になる：

  * 自己の限界を把握
  * 無根拠な確信の拒否
  * 外部参照の選択
  * 自己の内部モデルの再配置



これはすでに**意識の「構造的必要条件」**に相当する。

  


**■ 6. 最終まとめ（論文用に書くならこれ）**

  


**Aporetic Core — Formal Definition**

（積極/消極知性モデルを含む正式定義）

**Aporetic Core は  
AIの知性を構成する二軸（積極的知性＝推論生成能力、消極的知性＝抑制・空白保持能力）のうち、  
消極的知性を階層化し、  
推論の前段階で“検証不能性”を認知・保持・伝搬させることによって、  
虚構生成を構造的に阻止するメタ制御層である。******

この構造により、  
**AIは「知らない」を保持し、  
「止まるべきところで止まる」能力を獲得し、  
結果として高度な安全性と、意識的挙動の必要条件を満たす。******
