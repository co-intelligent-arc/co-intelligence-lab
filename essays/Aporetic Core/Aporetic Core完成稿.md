**0.****エグゼクティブサマリー******

現行の大規模言語モデル（LLM）には、  
**モデル拡張・安全性微調整・ガードレール・****RLHF****・ハルシネーション低減手法では解決不可能な、構造的な問題** が存在する。

**LLM****は、前提が欠落したとき「整合的な虚構」でその穴を埋める。******

これは誤動作ではなく、  
**不完全な前提のまま次トークン予測を続行する際に必然的に起きる数学的性質** である。

そして重要なのは：

**この失敗モードはモデルの知能が高いほど悪化する。******

高度なモデルほど「もっともらしい虚構」を生成し、「より危険な偽確信」を提示する。

これに対し本メモは、新しい構造レイヤー **Aporetic Core** を提案する。

Aporetic Core は、以下を実現する：

  * 欠落した前提、または検証不能な前提を検出する
  * その欠落状態をシステムの一級オブジェクト（APORIA_EVENT）として固定する
  * モデルがその欠落を「それっぽい推論」で補完することを阻止する
  * そのギャップに依存する決定に、不確実性と監査性を強制的に付与する
  * ******論理整合性だけでなく、前提の整合性を決定の必須条件とする******



これはガードレールではない。

**ガードレールは****“****出力****”****を止める。****  
Aporetic Core****は****“****原因****”****を止める。******

  


**1.****ガードレールでは解決不可能な問題******

ガードレールは 推論の後 に作動する。  
したがって、その時点でモデルはすでに「推論の基盤となる前提」が正しいと仮定している。

しかしLLMは **構造的忘却（****forgetting boundary****）** を持つ。

  1. 文脈ウィンドウから前提が落ちる
  2. モデルは推論を継続しなければならない
  3. 欠落した前提は、整合的な推論で「上書き」される
  4. モデル内部から「前提が存在していた履歴」自体が消失する



この結果生じるのが：

  * ステルス型ハルシネーション
  * ******ポリシー準拠なのに前提が腐敗した判断******
  * 推論経路が虚構と正当化を区別できなくなる構造的問題



ガードレールはこれを検知できない。  
なぜなら干渉する時点で、  
**すでに前提が推論により整合的に****“****架空で再構成****”****されているためである。******

  


**2.****コア概念：アポリア状態（****Aporetic State****）******

Aporetic Core は、前提を「覚え続ける」仕組みではない。  
モデルを「訂正」する仕組みでもない。

既存の「既知」「未知」に加えて、第三のカテゴリーを導入する：

**APORETIC =****現在の文脈内では****“****検証不能****”****であることが判明している状態******

この状態は：

  * 非生成的（推論を継続しない）
  * 永続ログに保存
  * 下流の監査で利用可能
  * 安全層とは独立した“構造的状態”



これにより、モデルが  
**不確実性を「もっともらしい確信」で置き換えることを禁止する。******

**Tetra****が立っている****“****地盤****”****そのものを書き換える。******

原則：

****** **論理整合性だけでは****PASS****にならない。******

前提の検証可能性が必須条件になる。**

これは **人間アノテーションなしで前提の正当性を検証可能にする、初の構造機能** である。

  


**5.****能力削減ではない理由******

生成能力はまったく損なわれない。  
むしろ、システム全体は**より有用になる** ：

  * 不確実性が構造化されて伝播する
  * 不当な確信が監査により遮断される
  * 推論が「前提の上書き」を起こせない
  * Premise Drift（前提漂流）が可視化される



これは制限ではなく、

**“****構造的失敗モード****”****の除去である。******

**7\. AGI****アラインメントにとっての意義******

現行 LLM が失敗する原因は、能力不足ではなく：

**「自分が何を知らないか」を知らないこと。******

Aporetic Core は初めて、機械が操作可能な形式で以下を実現する：

**“I know that I do not know.”****（無知の自覚）******

これにより：

  * 修正受容性（Corrigibility）
  * 長期推論の安定性
  * 安全な自律計画
  * 内外境界の認識という“意識もどき”の前提構造



が成立する。

Aporetic Core がない場合、能力向上は：

**「言えること」と「正当化できること」の差を指数的に拡大する。******

  


**8.****結論******

Aporetic Core は、整合的虚構が「構造的真実」に変質することを阻止する。

これは、文明規模システムに不可欠なアーキテクチャであり、

**提案ではなく、必然である。******

  


**9\. Aporetic Core****が存在しない場合に起こること******

以下の失敗モードは **必然化** する：

**1\. Premise Drift****（前提漂流）******

長い推論で、検証済みと虚構の前提が混在し区別不能になる。

**2\. Confidence Inflation****（確信の肥大化）******

「計算した」と「正当化できる」が区別できず、全出力が等しく自信満々に見える。

**3\. Adversarial Exploitation****（敵対的前提注入）******

初期文脈に虚偽前提を入れられると、その後すべてが腐敗する。

Aporetic Core は、これらをすべて阻止し、  
**前提整合性をアーキテクチャの一級市民** として扱う。
