# 老朽化メトリクス（DDI-2）

**DDI-2：老朽化メトリクス（正式版・外部保存用）**

_Dynamic Degeneration Index – Version 2.0_ __

  


**0\. 目的と前提**

**0.1 目的**

DDI-2は、  
**組織・制度・文明構造が「健全な動的平衡」を維持しているか、それとも老朽化・硬直・癌化に向かっているかを、観測可能な指標により判定するための計量体系** である。

評価対象：

  * 企業
  * 国家・行政
  * 学術機関
  * NPO
  * 文明レベルの制度構造



  


**0.2 基本思想（重要）**

  * 主観は排除しない
  * ******主観の置き場所を固定する******
  * 単一スコアで善悪を断定しない
  * ******時系列とバランスを重視******
  * 測定が最適化を歪めること（グッドハートの法則）を前提に設計する



  


**1\. 測定の基本ルール（共通仕様）**

**1.1 正規化（Normalization）**

すべての指標は以下で正規化する：

  * 業界サイクル（IT / 行政 / 教育 / 製造 等）
  * 組織規模（従業員数の対数）
  * 文化圏（国・労働慣行）



👉 **絶対値ではなく、同業種内相対評価を基本とする******

  


**1.2 時系列重視**

  * 単一時点スコアは禁止
  * 最低3点（過去 → 現在 → 直近）で測定
  * 重視するのは：
    * 変化量（Δ）
    * 変化の加速度（Δ²）



  


**1.3 外部測定原則**

  * ******公開情報・観測ログのみで再現可能** であること
  * 内部データが必要な指標は「補助指標」として扱う



  


**2\. 指標定義（Core Metrics）**

  


**① 構造変更頻度指数（MRR：Metabolic Renewal Rate）**

**目的：**  
組織が不要な構造を捨て、新しい構造を導入できているか

**基本式（正規化後）：******

  


MRR = (廃止数 + 新設数) / 総制度数

**観測対象：******

  * 組織改編
  * プロダクト終了・統合
  * 制度・方針の明確な撤退



**質的重み付け：******

  * 撤退理由が説明可能：+1
  * 説明不能・場当たり的：-1
  * 新設後3年定着率で補正



**注意：******

  * 高すぎるMRRは「自己崩壊リスク」
  * 低すぎるMRRは「硬直・老朽化」



  


**② 外部知流入比率（BPI：Boundary Permeability Index）**

**目的：**  
外部の知・文化・技術を吸収し、内部に定着させられているか

**観測指標：******

  * 外部出身リーダー比率
  * 外部由来技術・思想の導入数
  * ******3年後定着率（最重要）******



  


定着率 = 3年後も利用されている外部導入要素 / 導入総数

**補助指標：******

  * 外部人材の在任期間（3–7年が最適帯）



**注意：******

  * 流入だけ多く定着しない場合は「寄生的若返り」



  


**③ 非最適行動許容率（SSC：Slack & Serendipity Capacity）**

**目的：**  
短期最適化から逸脱する「余白」が制度的に確保されているか

**代理指標（外部測定可）：******

  * 探索枠（R&D・安全・基礎研究）の制度的存在
  * 成果を問わない継続年数
  * 研究・公開活動の非収益比率



**推奨測定式：******

  


探索枠率 = 成果非拘束R&D予算 / 総R&D予算

**注意：******

  * 無駄との違いは「制度化されているか」で判別
  * 0に近い場合、組織は確実に老いる



  


**④ 障害回復半減期（RAL：Recovery Adaptation Latency）**

**目的：**  
失敗・危機から学習し、再発を防げているか

**危機カテゴリ：******

  * 財務
  * 信用・規制
  * 技術・安全



**実効回復率：******

  


実効回復率 = 1 / (回復時間 × (1 + 再発率))

**正規化：******

  * 組織規模 × 業界係数で補正



**注意：******

  * 速い回復 ≠ 健全
  * 再発が多い場合は減点



  


**⑤ 意思決定集中指数（MFS：Monocentricity Factor Score）**

**目的：**  
単一人物・単一系統への依存度（SPOF）を検出

**観測指標：******

  * 最終決裁者依存率
  * 不在時の意思決定停止頻度
  * 決裁速度の分散



  


決裁分散 = 標準偏差（決裁時間）

**補助指標：******

  


代行発動率 = 不在時に代行決裁された案件数 / 総案件数

**注意：******

  * 高すぎる集中は致命的
  * 完全分散も非効率



  


**⑥ 下方発火率（SOV：Spontaneous Organic Vitality）**

**目的：**  
下位層から構造変化が発火しているか

**測定要素：******

  * ボトムアップ提案の採用率
  * ******影響度で重み付け******



  


重み付き採用率 = Σ(採用提案の影響度) / Σ(全提案の影響度)

**多様性指標：******

  


提案者エントロピー = -Σ(pi × log(pi))

**注意：******

  * 小粒提案の量産は評価しない
  * 影響度と多様性が重要



  


**3\. 偽装検知（Anti-Spoofing）**

**3.1 痛覚指標（PAI：Pain Accompaniment Index）**

**問い：******

その変化は、組織に痛みを伴っているか？

観測例：

  * 既存予算・権限・利権の削減
  * 重要ポジションの廃止
  * 不都合な撤退の公表



**痛みなき改革は減点******

  


**3.2 バランス評価**

  * 単一指標突出 → 機能の癌化
  * 指標間相関を必ず確認



  


**4\. 出力形式（必須）**

  * 各指標スコア
  * 時系列変化
  * バランス所見
  * ******反証ログ******
    * 「この評価が誤診である可能性」



  


**5\. 解釈上の注意（重要）**

  * DDI-2は「善悪」を決めない
  * ******崩壊リスクの位置と方向を示す******
  * 評価は常に暫定
  * 再測定前提



  


**6\. 定義上の結論**

**老朽化とは：******

変化できなくなることではない  
**変化が「最適化」しか残らなくなること******
