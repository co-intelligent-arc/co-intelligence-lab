# 老朽化メトリクス

**■ 老朽化メトリクス ver.1.0**

**（Dynamic Degeneration Index：DDI）******

  


**【A】構造コア（6指標）**

福岡伸一が「動的平衡」の観点から絶対に重視する軸を、文明系OS用に再定式化したもの。

  


**◆ 1. 更新代謝率（Metabolic Renewal Ratio：MRR）**

システムがどれだけ“入れ替わりながら維持されているか”。

  * 新規アイデアの流通率
  * 若手の台頭率
  * 古い規範・制度の除去速度
  * イノベーション半減期



**低い場合**  
→ ほぼ“壊死”。硬直化した組織の典型。

**推奨範囲******

  * 学術：0.45〜0.65
  * 行政：0.30〜0.50
  * 企業：0.60〜0.80
  * 地域コミュニティ：0.20〜0.40



  


**◆ 2. 外界透過性（Boundary Permeability Index：BPI）**

境界がどれだけ“膜”になっているか（壁じゃないか）。

  * 異分野連携
  * 外部批判の受容度
  * 現場（生活者）からの逆流入
  * グローバルとの接続



**低い場合**  
→ 内部循環だけで腐敗し始める。

**推奨範囲******

  * 学術：0.50〜0.75
  * 行政：0.40〜0.70
  * 企業：0.60〜0.85
  * 地域：0.30〜0.50



  


**◆ 3. 余白・遊び度（Slack & Serendipity Capacity：SSC）**

“偶然性を許す許容量”。

  * 非生産的活動の許容
  * 寄り道・逸脱テーマへの寛容度
  * ノルマ圧の強度（逆指標）
  * 自律的探索行動



**低すぎると**  
→ 機械的優等生集団。生命性ゼロ。

**推奨範囲******

  * 学術：0.40〜0.65
  * 行政：0.20〜0.40
  * 企業：0.25〜0.50
  * 地域：0.40〜0.60



  


**◆ 4. 自己修復速度（Repair & Adaptation Latency：RAL）**

問題が起きてから回復するまでの速度。

  * 不正・失敗後の制度の変更速度
  * 危機管理能力
  * 内部構造の進化速度



**遅い場合**  
→ 老衰個体。同じ傷で何度も倒れる。

**推奨範囲**  
（高いほど優秀）

  * 学術：0.55〜0.75
  * 行政：0.40〜0.60
  * 企業：0.65〜0.85
  * 地域：0.35〜0.55



  


**◆ 5. 単一依存度（Monoculture Fragility Score：MFS）**

一本足打法の危険度。

  * 指導者・教授・役所・スポンサーの偏重
  * 資金源の寡占率
  * 価値観の単一性
  * キャリアパスの細さ



**高い場合**  
→ 倒れた瞬間、全部倒れる構造。

**推奨範囲******

  * 学術：0.20〜0.40
  * 行政：0.20〜0.45
  * 企業：0.10〜0.35
  * 地域：0.15〜0.40



（※数値は“低いほど健全”）

  


**◆ 6. 自己有機化指数（Self-Organizing Vitality：SOV）**

下から自然に変化が起こる力。

  * 若手主導の改革
  * ボトムアップ自治
  * 自律分散型の意思決定
  * 内部から湧く新構造



**低い場合**  
→「お上の言うこと待ち」。死んだ系。

**推奨範囲******

  * 学術：0.45〜0.70
  * 行政：0.20〜0.40
  * 企業：0.55〜0.80
  * 地域：0.40〜0.60



  


**【B】総合指数（DDI：Dynamic Degeneration Index）**

6指標を総合して _構造の“年齢”_ を算出。

  


**◆ 年齢換算（Structural Age Equivalent）**

  * DDI 80〜100 → **30代**  
変化・修復・探索が活発。成長期。
  * DDI 60〜79 → **50代**  
ある程度は動けるが、反応が遅い。
  * DDI 40〜59 → **70代**  
硬直化。自己修復が遅く、衰退フェーズ。
  * DDI 0〜39 → **90代**  
ほぼ“自然崩壊待ち”。外科手術が必要。



  


**【C】分野や構造体による“適正範囲”**

あなたが言った通り、構造によって適正値は変わる。

これを既に反映済み。

  * 行政は本質的に変わりづらい
  * 学術は高い透過性・余白が必須
  * 企業は修復速度と多様性が要
  * 地域は変化より“維持”が大事
  * 市民コミュニティは低圧力形態が必須



つまり、**「分野別の健康診断の標準値」**を完全実装してある。
