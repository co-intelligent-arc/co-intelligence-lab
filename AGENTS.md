# AGENTS.md

## Repository purpose
This repository stores research assets for the Co-Intelligence Project.

## Core structure
- `papers/OMD/` = Organizational Metastability Dynamics
- `papers/RD/` = Recomputation Dynamics
- `papers/RLAF/` = RLAF Revisited

## Source-of-truth policy
- Latest working drafts should be placed in each paper's `drafts/` folder.
- Older versions should be moved to `archive/` or renamed with clear version tags.
- Do not overwrite files without preserving version history.

## Editing policy
- Prefer minimal, explicit edits.
- Preserve argument structure unless asked to restructure.
- Keep filenames stable and versioned.
- Treat theoretical notes and submission-ready drafts as different document types.

## Writing policy
- OMD = empirical anchor
- RD = general theory core
- RLAF = individual-scale AI agency theory

## Safety rule
- When uncertain which file is canonical, do not guess. Flag the ambiguity explicitly.
