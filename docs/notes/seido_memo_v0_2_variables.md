## 1. このメモの目的

v0.1で固定した最小核定義——「生動とは差異を保持し、その差異に対して再計算し続ける再計算的存在運動である」——を、変数として記述可能な形に降ろす。

完成式はまだ作らない。今回固定するのは**変数辞書**と**変数間の関係の方向性**だ。

---

## 2. 変数辞書

### D（差異保持 / difference-retention）

**概念定義：**
差異が将来生成しうる立脚点の非同一性が、構造として維持されている度合い。

**否定定義（重要）：**
DはAではない——Aを現在表出しているズレの量と定義したとき。今ズレているかどうかはDの本体ではない。立脚点が別であれば、今は一致していてもDは高くありうる。逆に、表面的にズレていても立脚点が実は同じならDは低い。

**二層の操作化：**
- D（設計側）＝各トラックへの入力・役割・情報セットの非同一性をどれだけ意図的に構築したか
- D（観測側）＝異なる条件下で差異が表出した実績から推定される立脚点の独立性

**観測指標の方向：**
出力差ではなく前提差を見る。具体的には：
- 立脚点の入力差
- 参照している価値軸の差
- 問題定義の差
- 時間射程の差
- 制度的前提の差

**羊飼いモデルとの接続：**
DIVERGEは現象的差異を記録する。Dは構造的差異保持を測る。今DIVERGEがゼロでも、Dが高ければ未閉鎖は残っている。

---

### R（再計算可能性 / recomputability）

**概念定義：**
保持された差異を素材として、内部状態を更新し続けられる能力の維持度。

**否定定義：**
再計算は変化一般ではない。外部から強制された変化や単純な状態遷移は再計算ではない。再計算は差異を検出し、その差異を素材として内部構造を能動的に更新する過程だ。

**DとRの関係：**
DとRは独立ではなく相互依存している。Dがゼロなら再計算の素材がなく、Rは機能しない。Rがゼロならば差異があっても更新が起きず、生動は止まる。

**暫定的な関係式の方向：**
積モデル（D × R）が直感的だが問題がある——Dが微小でRが巨大、あるいはその逆が同じ生動量を与えてしまう。最小値モデル（min(D, R)）はボトルネック制約として自然だが、現実の滑らかさを失う。現時点では**動的相互規定**として扱い、固定式にしない。これはv0.3以降の課題。

---

### S（生動量 / seido intensity）

**概念定義：**
生動の強さの近似量。DとRが両方維持されているとき高く、どちらかが低下すると下がる。

**暫定近似式（v0.2段階）：**
```
S ≈ f(D, R)　ただしf の形はまだ固定しない
最低条件：D→0 のとき S→0、R→0 のとき S→0
```

**注意：** Sは単調増加ではない。D・Rが高くても、散逸（Λ）が大きければSは低くなりうる。

---

### C（創造力 / generative capacity）

**概念定義：**
差異の再計算から新しい構造・問い・意味が生成される能力。

**位置づけ：**
DとRがあれば必ずCが出るわけではない。Cは再計算の産物であり、生動の出力側に位置する。生動が痩せるとCも落ちる。

**暫定式の方向：**
```
C ∝ R × (何らかの生成効率係数)
```

---

### X（有効変位 / effective displacement）

**概念定義：**
再計算によって実際に内部状態が動いた量・方向の変化度合い。

**Cとの違い：**
Cは生成能力、Xはその能力が実際に機能した結果としての変位。能力があっても使われなければXは小さい。

---

### Λ（減衰・散逸 / decay / dissipation）

**概念定義：**
生動を弱める方向に働く力の総称。差異の均質化、再計算回路の硬直化、立脚点の同質化などが含まれる。

**位置づけ：**
生動は孤立系では自然に減衰する方向に動く。生動を維持するには、ΛをDとRの更新で補償し続ける必要がある。これがv0.3で扱うネゲントロピーとの接続点だ。

---

## 3. 変数間の関係の方向性（暫定）

```
D（立脚点の非同一性維持）
    ↓ 差異を供給
R（再計算可能性）
    ↓ 再計算が走る
C（創造力）× X（有効変位）
    ↓ 生動量に寄与
S（生動量）
    ↑ 減衰
Λ（散逸）
```

**注意：** これは方向性の図であり、完成式ではない。特にD→Rの関係は相互依存であり、一方向の矢印で表すことには限界がある。

---

## 4. 固定真理と暫定真理の変数的理解

今回の議論で更新されたDの定義から導ける重要な含意：

**固定真理：** 動く可能性が構造として閉じている一致。D→0の状態。

**暫定真理：** 現時点では一致していても、立脚点の差異（D）が構造として残っており、将来の入力変化で動きうる一致。

この区別は羊飼いモデルのHARDの理解に直結する。HARDは永遠に正しい固定真理ではなく、**異質な立脚点がいま与えられた条件下で一致した強い暫定真理**として扱う。
