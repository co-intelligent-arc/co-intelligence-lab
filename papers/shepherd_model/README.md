## What this is

A function-based architecture for AI-mediated decision environments, organized around one criterion: after the loop has run, the human must stand more exactly at the fork than before.

**Three functions:** difference generation → difference reading → recomputation return  
**Two control variables:** D (difference retention) / F (feedback intensity)  
**Theoretical grounding:** Seido — the dynamic condition in which retained difference and recomputability remain mutually active

## Core claim

> Single-track AI mediation does not destroy judgment. It destroys the structural conditions under which decision — the act of accepting a value-laden trade-off as one's own — remains possible.
