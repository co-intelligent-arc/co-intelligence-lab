## Overview

This paper formalizes the process by which subject-injury proceeds — not as the destruction of a subject, but as the **silent cessation of recomputation** while surface functioning remains intact.

To describe this mechanism, three independently developed theoretical frameworks are integrated:

- **OMD** (Organizational Metastability Dynamics): identifies *Region B*, the diagnostic blind spot in which structural stability is preserved while recomputation capacity has ceased
- **RD** (Recomputation Dynamics): models adaptive capacity as A(e,u) = f(e)×g(u), showing that the depletion of exploratory diversity and the atrophy of update capacity amplify each other nonlinearly
- **RLAF** (Reinforcement Learning from AI Feedback): shows that subject integrity requires an autonomy tensor T rather than a scalar index, and identifies evaluative autonomy (T_eval) as the primary site of erosion

Across all three frameworks, **difference-retention (D)** functions as the shared upstream condition for recomputation. Subject-injury is defined here not as destruction but as **invisible degradation**: difference disappears, recomputation stops, evaluative autonomy is eroded, and value autonomy becomes fixed — while output continues and the system remains socially legible as normal or successful.

## Key Concepts

| Term | Definition |
|------|-----------|
| **Subject-injury** | The process by which a subject transitions toward Region B — not destruction, but the progressive loss of recomputation capacity |
| **Region B** | The state in which structural stability (σ) and cognitive autonomy (T_cog) remain while recomputation capacity (M), evaluative autonomy (T_eval) have ceased and value autonomy (T_val) has become fixed |
| **Difference-retention (D)** | The preservation and availability of difference inputs capable of prompting re-evaluation of the subject's existing frame; the common upstream condition across all three frameworks |
| **Invisible degradation** | The defining character of subject-injury: surface functioning is preserved while internal updating has ceased |
| **Autonomy tensor (T)** | T = (T_cog, T_aff, T_eval, T_mot, T_val) — the multi-component description of subject integrity; components erode in a specific sequence |

## Minimal Causal Chain

```
ω↑ + L_c↑ (parallel inputs)
  → C↑ (conformity pressure)
  → D↓ (difference-retention depleted)
  → Var(φ)↓ / e↓ / T_eval input impoverished
  → E_r_eff↓ → M↓ / u↓ → A(e,u) multiplicative degradation
  → T_eval paralysis → T_val becomes fixed
  → σ, T_cog remain
  → Region B (apparently normal, internally halted)
```

**In one sentence:** Judgment delegation depletes difference-retention; the depletion of difference-retention arrests recomputation; the arrest of recomputation erodes evaluative autonomy and fixes value autonomy. *The subject stops before it breaks.*
