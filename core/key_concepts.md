# 主要概念表 / Key Concepts

*Co-Intelligence Lab — 概念リファレンス*
*Last updated: 2026-06-07*

---

本表は、本研究プログラムで用いられる主要概念を定義・位置づけ・出典とともに一覧にしたものである。各概念は独立したものではなく、理論的連鎖の中でそれぞれの機能を担っている。

---

## 概念一覧

### Region B（領域B）

| 項目 | 内容 |
|------|------|
| **定義** | 探索的多様性（*e*）が中〜高であるにもかかわらず、更新能力（*u*）が低い状態。外形は正常に見えるが、内部の再計算機能がすでに停止している。 |
| **別称** | 外形正常・内部停止の崩壊状態 |
| **対応する他の領域** | Region A（*e* 高・*u* 高：健全）、Region C（*e* 低・*u* 低：崩壊表面化） |
| **なぜ危険か** | 崩壊が進行中にもかかわらず、表面指標（人口、売上、出力）が正常を示すため、従来の診断指標では検出できない |
| **実証的証拠** | OMD論文：低 *e*・低 *u* 市区町村が最高の人口流入を示す逆転結果（r = −0.458, p < 0.001） |
| **個人スケールの対応** | T\_cog（認知）が維持されたまま T\_eval（評価自律性）・T\_val（価値自律性）が侵食される状態（RLAF論文） |
| **出典** | [OMD](../papers/OMD/)、[RD](../papers/RD/)、[RLAF](../papers/RLAF/) |

---

### Recomputability（再計算可能性）/ M

| 項目 | 内容 |
|------|------|
| **定義** | システム（個人・組織・社会）が自己の評価枠組みを問い直し、差異を保持し、内部更新を継続できる能力の総体 |
| **記号** | M、または A(e, u) |
| **定式化** | A(e, u) = f(e) × g(u)（乗法構造：どちらか一方の崩壊が全体を消去する） |
| **構成要素** | *e*：探索的多様性（探索の幅）、*u*：更新能力（更新の深さ） |
| **個人スケールの対応** | 自律性テンソル T = (T\_cog, T\_aff, T\_eval, T\_mot, T\_val) における総合的な再計算能力 |
| **なぜ乗法か** | 高 *u* は崩壊した *e* を補えず、高 *e* は崩壊した *u* を補えない。加法モデルとの本質的差異。 |
| **診断上の含意** | M の低下は表面指標の悪化より先行する——診断困難の根本的源泉 |
| **出典** | [RD](../papers/RD/)、[OMD](../papers/OMD/)、[RLAF](../papers/RLAF/) |

---

### Difference Retention（差異保持）/ D

| 項目 | 内容 |
|------|------|
| **定義** | 複数の立脚点が非同一のまま保たれる度合い。差異が将来生成しうる構造的条件を保持する設計変数。 |
| **記号** | D |
| **二重機能** | （1）**創発変数**：差異が出現しうる構造的条件の保持。（2）**安全変数**：フィードバック強度 F による過剰収束への構造的抵抗条件。 |
| **D を高める設計軸** | 入力の非同一性、役割の非同一性、参照情報の非同一性、評価軸の非同一性 |
| **D が低い場合** | 複数トラックを動かしても実質的に同一の評価軸から出力が生まれ、差異は形式的にのみ存在する |
| **D と M の関係** | D がなければ差異は生成されず、差異がなければ再計算（M）は起動しない |
| **出典** | [Shepherd Model](../papers/shepherd_model/)、[RD](../papers/RD/) |

---

### Relational Knowledge（関係知）

| 項目 | 内容 |
|------|------|
| **定義** | 複数の情報地図の重ね合わせによって内部に形成・蓄積された潜在器が、アテンションの走査と受容的充填を通じて情報地図を再編する現象 |
| **最小過程** | 素材蓄積 → 潜在器形成 → 走査 → 採用 → 推論的充填 → 情報地図の再編 |
| **直列関係知** | 一つのトラック内部で、出力が次の問いを形成する縦方向の知の連鎖 |
| **並列関係知** | 異なるトラックの出力を横断的に読解することで生まれるトラック間の差異から形成される知の構造 |
| **高次関係知** | 直列と並列の循環によって生まれる、より深い知の構造 |
| **関係知と主体侵害** | AI が関係場の差異供給を均質化すると、潜在器の多様性が失われ M が低下する |
| **出典** | [関係知の設計（エッセイ）](../essays/relational_knowledge/)、[Subject Erosion Child Paper 3](../papers/subject-erosion-dynamics/child-paper-3/) |

---

### Latent Vessel（潜在器）

| 項目 | 内容 |
|------|------|
| **定義** | まだ意識化されていないが、後の走査によって意味構造の再配置を引き起こしうる、拘束付き構造空所 |
| **穴との区別** | 単なる空白（穴）ではなく、周辺拘束によって「入るべきものの型」が先取りされた構造 |
| **形成過程** | 他者・環境との相互作用が情報地図に素材を蓄積し、素材群のあいだに拘束付き構造空所が生まれる |
| **発火条件** | アテンションの走査が潜在器に到達し、推論による充填が受容されたとき |
| **設計可能性** | 周辺拘束の質・量・積み上がり順序・未閉鎖の選択によって、どのような器が形成されやすいかを半意図的に制御できる |
| **出典** | [意図的創発（エッセイ）](../essays/intentional_emergence/)、[関係知の設計（エッセイ）](../essays/relational_knowledge/) |

---

### Intentional Emergence（意図的創発）

| 項目 | 内容 |
|------|------|
| **定義** | 未知の問いや解が出現しうる器と配置を先に設計し、そこに推論をかけることで出現確率を偏らせる設計技術 |
| **核心的主張** | 創発は直接生成されるものではなく、出現条件を設計されうる一般現象 |
| **開放型 vs 閉鎖型** | 設計者の想定外に問いが出られる余地を保持する限り開放型；余地を閉じると認知誘導装置へ転化 |
| **天啓との関係** | 「突然のひらめき」は遅延認識であり、その前に器の形成過程がある——設計はこの前過程を対象とする |
| **操作変数** | L0（問いの地場）、周辺拘束の配置、アテンション地形の設計、半拘束的問い再生成 |
| **出典** | [意図的創発（エッセイ）](../essays/intentional_emergence/) |

### Ethics as Circuit Preservation（倫理の回路保全原理）

| 項目 | 内容 |
|------|------|
| **定義** | 再計算可能性の回路を構造として毀損する設計・運用・環境が倫理的問題の本体であるという原理 |
| **従来倫理との差異** | 規則遵守・配慮の倫理・帰結主義ではなく、回路保全という設計問題として倫理を立てる |
| **倫理的問題の三層** | 設計層（D の消去・返却機能の欠如）、運用層（差異が読解・返却されない）、環境層（T\_eval・T\_val の侵食） |
| **倫理的行為者の定義** | 「良いことをする」存在ではなく、「再計算可能性の回路を保全する設計を選ぶ」存在 |
| **Subject Erosion との関係** | 主体侵害は倫理的問題を含む——ただし「侵害した」という個人帰責ではなく、構造としての回路断絶として |
| **出典** | [中心命題](./central_thesis.md)、[Shepherd Model](../papers/shepherd_model/)、[Subject Erosion 親論文](../papers/subject-erosion-dynamics/parent-paper/) |

### Shepherd Model（羊飼いモデル）

| 項目 | 内容 |
|------|------|
| **定義** | 単一トラック AI 運用が意思決定を「決定」から「承認」へと縮退させる問題に対する、リスク低減型のアーキテクチャ設計原理 |
| **三機能** | 差異生成（Difference Generation）・差異読解（Difference Reading）・再計算返却（Recomputation Return） |
| **制御変数** | D（差異保持）と F（フィードバック強度） |
| **読解カテゴリ** | HARD（排除差異）・DIVERGE（構造差異）・OPEN（価値的トレードオフを含む返却対象差異） |
| **設計基準** | ループが一巡した後、人間は以前より正確にその分岐点に立っていなければならない |
| **既存手法との差異** | RAG・RLHF・アンサンブルは出力層の問題を解く；Shepherd Model は意思決定構造層の問題を解く |
| **主体保障との接続** | 返却は倫理的配慮ではなく、主体が再計算しうる構造的条件の設計として基礎づけられる |
| **出典** | [Shepherd Model](../papers/shepherd_model/)、[中心命題](./central_thesis.md) |

---

### Reopening Force（再開放力）

| 項目 | 内容 |
|------|------|
| **定義** | Region B の閉鎖状態から系を再び開放し、再計算可能性を回復させる外的または内的な力・条件 |
| **なぜ非対称か** | Region B への移行は緩やかで不可視だが、再開放には Region B 以前の水準の外的差異入力が必要となる（ヒステリシス） |
| **ヒステリシスとの関係** | 閉鎖から回復への経路は開放から閉鎖への経路と異なる——非線形の回復非対称性 |
| **Shepherd Model における位置** | Shepherd Model の再計算返却機能が、個人スケールで Reopening Force を設計的に供給する |
| **Design implications** | 再開放を偶然に期待するのではなく、Reopening Force が発生しやすい構造条件を設計する必要がある |
| **出典** | [RD](../papers/RD/)、[Subject Erosion 親論文](../papers/subject-erosion-dynamics/parent-paper/)、[Shepherd Model](../papers/shepherd_model/) |

## 概念間の構造的連関

```
差異保持 D
    ├── 差異生成を可能にする（創発変数）
    └── 過剰収束を抑制する（安全変数）
         ↓
     差異の生成
         ↓
     差異読解 → HARD / DIVERGE / OPEN
         ↓
     再計算返却（OPEN → 人間へ）
         ↓
  再計算可能性 M の維持
         ↓
    Region B を回避
         ↓
  倫理の回路保全（回路の断絶なし）
```

単一トラック依存・D の消去・返却機能の欠如は、この回路を設計レベルで断ち切り、M を低下させ、Region B を不可視のまま進行させる。
