# Bridge: 主体論シリーズ ↔ Inquiry Preservation Framework

このブリッジ文書は、主体論シリーズ（`docs/subject_theory_EN.md`）とIPF（`docs/inquiry_preservation_framework_v1.1.md`）の接続構造を、AIおよび人間の双方が参照できる形で記述する。

---

## 1. 接続の一文

主体論シリーズは、本体系における問い形成主体の基礎構造を与える。TFLが「問いが形成される時間的機構」を記述するのに対し、主体論は「その機構を担う主体がどの条件で主体として機能し、どの条件で見かけ上正常なまま停止し、どの条件で保護されうるか」を記述する。したがって、Region Bは本体系における多スケール失敗構造の原型であり、主体保護の四原則は認知免疫および問い形成保全の制度的条件として位置づけられる。

## 3. 方向性のある接続

### 主体論 → TFL

主体論が答える問い：誰が、どのような状態なら、問いを再計算できる主体なのか。  
TFLが答える問い：その主体の中で、外部入力がどう問いへ変わるのか。

**接続点：** TFLの「主体固有表象」は、主体論のD・M・T_eval・T_val・存在史・関係文脈によって支えられる。同じ入力が異なる表象になるのは、主体がD・M・T_evalの異なる状態にあるからである。

### Region B → 多スケール失敗構造

```
Region B（個人） → グッドハート化（制度） → 物語平均化（社会） → 文明的Region B（文明）
```

共通構造：外形上の正常動作と内部的な再計算停止の共存。どのスケールでも自己隠蔽的。

### 主体保護四原則 → 認知免疫（二層防御）

```
制度層：主体保護四原則（評価空間の再設計）
個人層：認知免疫（AI出力に対する保留・照合・再計算）
```

制度が保留を正統化しない環境では、個人の認知免疫も発揮できない。両者の同時整備が問い形成保全の最小構造的条件。

### designed simplification → コスト勾配・グッドハート化

```
設計による評価空間の単純化（主体論）
= コスト勾配の制度的形態（第9章）
= グッドハート化の認知的形態（第10章）
```

## 4. AIへの読み方指示

この体系を文脈として使う場合、主体論とIPFは同一プログラムの異なる解像度の記述である。

- **主体論固有の語彙**（T_cog、σ、S_r、ΔS_r等）はIPFの語彙に直接対応しないが、IPFのL1（主体論層）の原典として参照可能。
- **Region B**：IPF全体を通じて「同型失敗構造」として反復される概念の原型。スケール指定のない「失敗」への言及は、ほぼ全てRegion Bの変形として読める。
- **四原則の乗法的構造**：IPFの「設計単独では不十分」という主張の制度論的根拠。
