# 問いの保全 / The Preservation of Inquiry

**AI媒介最適化環境における生動・主体・再計算・存在史・フィードバック統治の統合理論体系**

*An Integrated Theoretical System of Seido, Subjecthood, Recalculation, Existence-History, and Feedback Governance in AI-Mediated Optimization Environments*

---

## 中心的な問い

> AIが答えを出す時代に、人間はいかにして自分の問いを失わずにいられるのか。

あるいは、より広く言えば、

> AI、資本主義、制度的最適化、認知的省コスト化が重なり合う環境の中で、人間はいかにして問いを形成し、違和感を保持し、意味を再計算し、自らの存在方向を引き受け続けることができるのか。

---

## このリポジトリは何か

ここにあるのは、論文集でも、結論でも、完成した答えでもない。

**理論地図**である。

著者（田中佑樹）が複数年にわたって並行開発してきた理論群——主体論、再計算論、問い再生成の所在移動（QRD）、時間的フィルタリング・ループ（TFL）、関係知論、認知的短絡、コスト勾配、グッドハート化、物語の平均化、文脈建築、認知免疫、存在史と人間の居場所、フィードバック統治——を、単一の体系として接続した地図である。

各理論は個別のジャーナル論文として投稿・記録されているが、一論文を読んでも体系の全体像は見えない。このリポジトリは、その立体を一枚で見せるために作られた。

同時に、**AIに読ませることを想定した文脈母艦**でもある。AIとの対話や研究作業において、このリポジトリを文脈（コンテキスト）として投入することで、概念間の干渉を防ぎ、体系全体を参照可能にする。

---

## 体系の核心

**最も重要な一文：**

> AIは、誤答によってだけでなく、**正答によっても**人間の問い形成を短絡しうる。

既存のAIリスク言説（誤情報・幻覚・バイアス）は、害を出力の**欠陥**に結びつける。能力が上がれば害が減る、という想定だ。しかし本体系が指定する害は逆に動く——出力が正確で、統合されていて、有用であるほど、人間が自分で問いを形成する時間的条件は消費される。**これは能力曲線が解決する問題ではなく、能力曲線そのものが悪化させる問題だ。**

**最も重要な非対称性：**

> AIは文脈で鳴る。人間は存在史で照合し、再計算する。

## 中核概念

| 概念 | 一行定義 |
|---|---|
| **生動（Seido）** | 差異保持と再計算可能性によって支えられる動的存在形式 |
| **再計算（Recalculation）** | 判断・問い・自己理解・方向性を固定せず組み替える能力 |
| **QRD** | 問い再生成の所在が人間からAIへ移動すること |
| **TFL** | 外部入力が人間固有の問いへ変わるまでの時間的過程（探索→保留→統合） |
| **Region B** | 外形上の正常動作と内部的な再計算停止の共存 |
| **認知的短絡** | AI等によって探索・保留・統合の過程が短縮・先取りされること |
| **コスト勾配** | 低コスト化への人間挙動・組織最適化・AI自動化の結合構造 |
| **グッドハート化** | 代理指標が目的を食い、再接続回路が失敗すること |
| **物語の平均化** | 集合スケールでの意味・問い・物語の分散低下 |
| **文脈建築** | AIが鳴る場を、概念・先行出力・違和感の配置によって設計すること |
| **認知免疫** | 正確で有用なAI出力による短絡への耐性 |
| **存在史** | 場をまたいで持続する身体・記憶・失敗・問い・責任の履歴 |
| **存在史の粘性** | 場に流されるが完全には流されない、場を超えた持続性 |
| **幸福の再計算可能性** | 自分にとっての幸福を問い直し、選び直し、引き受け直せる能力 |
| **人間の居場所** | 非必要性の中で存在方向を引き受ける能動そのもの |
| **フィードバック統治** | 何をフィードバックとして選び、どこへ戻し、どの強度で更新するかを統治すること |

→ 全概念の定義は [`glossary.md`](./glossary.md) を参照

## 体系の動的性格

このリポジトリは完成した教義ではない。

理論体系は更新される——下位理論群が成熟するにつれ、上位理論（特に生動論）が本格的に記述される。個別論文の査読・修正を経て、接続が精密化される。バージョン番号はその含意の実装である。

本体系が「再計算可能性の保全」を主張する以上、**体系自身が再計算可能でなければならない。**
