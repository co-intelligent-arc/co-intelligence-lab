# co-intelligence-lab
A research repository for the Co-Intelligence Project — theoretical, empirical, and methodological work on recomputation, organizational adaptation, and AI-mediated agency.

## The Trilogy

Three interconnected papers sharing a common core: **recomputation capacity** as the unifying construct across individual, organizational, and civilizational scales.

| Paper | Scale | Role | Status |
|-------|-------|------|--------|
| [OMD](papers/OMD/) | Social / Municipal | Empirical anchor | v0.9 — under review at *Chaos* |
| [RD](papers/RD/) | General theory | Theoretical core | v0.3.4 — targeting *Entropy* |
| [RLAF](papers/RLAF/) | Individual / AI agency | Micro-foundation | v0.1 — early draft |

### Shared Architecture

```
RLAF (individual)  →  RD (general theory)  →  OMD (social/empirical)
T = (T_cog, T_aff, T_eval, T_mot, T_val)
         ↓
  A(e, u) = f(e) × g(u)
         ↓
  Region A / B / C  +  hysteresis  +  demographic buffering
```

The core claim across all three papers: **deterioration becomes visible only after the internal update system has already stalled.**
